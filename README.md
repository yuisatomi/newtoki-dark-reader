# 뉴토끼 다크 리더

[스크립트 설치](https://raw.githubusercontent.com/yuisatomi/newtoki-dark-reader/main/newtoki-dark-reader.user.js)

Tampermonkey가 설치된 브라우저에서 위 링크를 열어 설치합니다. 새 버전을 배포할 때 `newtoki-dark-reader.user.js`의 `@version`을 올리면 설치된 기기에서 자동 업데이트됩니다.

## 브랜치 구분

- `source`: 전체 소스, 동기화 서버, 테스트 및 문서 관리
- `main`: Tampermonkey 배포 전용 (`README.md`, `newtoki-dark-reader.user.js`)

배포 주소는 항상 `main` 브랜치의 raw 스크립트이며, 전체 절차는 `AGENTS.md`를 따릅니다.

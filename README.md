# 뉴토끼 다크 리더

[스크립트 설치](https://raw.githubusercontent.com/yuisatomi/newtoki-dark-reader/source/newtoki-dark-reader.user.js)

Tampermonkey가 설치된 브라우저에서 위 링크를 열어 설치합니다. 새 버전을 배포할 때 `newtoki-dark-reader.user.js`의 `@version`을 올리면 설치된 기기에서 자동 업데이트됩니다.

기본 브랜치 `source`에서 서버, 스크립트, 테스트와 문서를 관리합니다. 이전 `main` 설치 주소는 호환용 `main` 태그에서 5.18을 계속 제공합니다. 앞으로 업데이트를 받으려면 위 `source` 링크로 설치 주소를 바꾸세요.
